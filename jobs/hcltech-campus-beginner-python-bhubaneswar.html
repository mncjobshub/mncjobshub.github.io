Job Description

HCLTech is looking for enthusiastic and motivated fresh graduates who have a passion for programming and software development. Selected candidates will work with experienced engineering teams to develop, test and maintain Python-based applications. Along the way they will get exposure to modern software development practices, automation, AI and cloud technologies. The opening is listed under the Campus Beginner category and the work location is Bhubaneswar, Odisha.

On the job you will write and maintain Python applications and scripts, follow coding standards, and debug issues with guidance from senior developers. You will take part in code reviews and team discussions, work with databases to store and retrieve application data, and collaborate with cross-functional teams to understand business requirements. You will also support automation, data processing and application enhancement work, and keep learning new technologies and best practices.

The posting does not list a salary, batch or detailed skill criteria on the page we reviewed, so check the official HCLTech page before you apply. To prepare, revise Python fundamentals such as data structures, functions and file handling, practise basic SQL, and keep one or two small Python projects ready to explain in an interview.

Key Responsibilities

  • Develop, test and maintain Python applications and scripts.
  • Write clean, efficient and reusable code that follows coding standards.
  • Debug and troubleshoot software issues with guidance from senior developers.
  • Take part in code reviews and team discussions.
  • Work with databases to store and retrieve application data.
  • Collaborate with cross-functional teams to understand business requirements.
  • Support automation, data processing and application enhancement activities.
  • Keep learning new technologies and best practices.

Eligibility & Requirements

Eligibility: Fresh graduates with a passion for programming; detailed criteria are on the official HCLTech page

  • Fresh graduate with a passion for programming and software development.
  • Working knowledge of Python.
  • Basic understanding of databases.
  • Enthusiasm for learning automation, AI and cloud technologies.
  • Willingness to learn from senior developers and work in a team.
