SQL is the first skill most data analyst interviews test. The questions below come up again and again for fresher roles. Practise each one on a real table instead of only reading the answer, and learn to explain your query out loud.

1. What is the difference between WHERE and HAVING?

WHERE filters rows before grouping. HAVING filters groups after GROUP BY and can use aggregate functions.

SELECT department, COUNT(*) AS employees
FROM employees
WHERE status = 'active'
GROUP BY department
HAVING COUNT(*) > 10;

2. Explain the different types of JOIN

  • INNER JOIN returns only rows that match in both tables.
  • LEFT JOIN returns all rows from the left table and the matching rows from the right; unmatched right columns are NULL.
  • RIGHT JOIN is the mirror image of LEFT JOIN.
  • FULL OUTER JOIN returns all rows from both tables, matched where possible.

A common follow-up: "find customers who never placed an order". Use a LEFT JOIN and filter where the right side is NULL.

SELECT c.customer_id, c.name
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.customer_id
WHERE o.order_id IS NULL;

3. How do you find duplicate records?

SELECT email, COUNT(*) AS cnt
FROM users
GROUP BY email
HAVING COUNT(*) > 1;

4. How do you find the second highest salary?

Using a subquery:

SELECT MAX(salary) AS second_highest
FROM employees
WHERE salary < (SELECT MAX(salary) FROM employees);

Using a window function, which also works for the Nth highest:

SELECT salary
FROM (
  SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM employees
) t
WHERE rnk = 2;

5. What is the difference between RANK, DENSE_RANK and ROW_NUMBER?

  • ROW_NUMBER gives a unique number to every row, even when values tie.
  • RANK gives tied rows the same rank and leaves gaps after them (1, 1, 3).
  • DENSE_RANK gives tied rows the same rank without gaps (1, 1, 2).

6. How does SQL handle NULL values?

NULL means unknown, so NULL = NULL is not true. Use IS NULL or IS NOT NULL. Use COALESCE to replace NULL with a default value.

SELECT name, COALESCE(phone, 'not provided') AS phone
FROM customers;

7. What is the difference between UNION and UNION ALL?

UNION removes duplicate rows from the combined result. UNION ALL keeps all rows and is usually faster because it skips the duplicate check.

8. What is a CTE and when do you use it?

A common table expression (WITH clause) gives a name to a temporary result so a long query becomes easier to read and reuse.

WITH monthly AS (
  SELECT DATE_TRUNC('month', order_date) AS month, SUM(amount) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT month, revenue
FROM monthly
ORDER BY month;

Date functions differ between databases, so be ready to mention the function for the database used by the employer.

9. How do you calculate a running total?

SELECT order_date,
       amount,
       SUM(amount) OVER (ORDER BY order_date) AS running_total
FROM orders;

10. What is the difference between a primary key and a foreign key?

A primary key uniquely identifies each row in a table and cannot be NULL. A foreign key is a column that refers to the primary key of another table and keeps the relationship between the two tables consistent.

How to prepare

  • Practise on real tables with a few thousand rows, not only tiny examples.
  • Say your approach aloud before you write the query: which tables, which join, what grouping.
  • Learn to check your result: row counts before and after a join, and whether duplicates appeared.
  • Prepare one project where you used SQL to answer a business question, and explain the insight you found.
